# HitMacro – Nutrition Analytics

A data analytics project focused on nutrition tracking, daily calorie and macronutrient consumption, personalized nutrition targets, and interactive reporting.

## Project Overview

HitMacro is a nutrition analytics project that helps users track their daily food intake, monitor calories and macronutrients, and compare actual consumption against personalized nutrition targets.

The project combines data management, calculations, SQL analysis, Python and Power BI visualization to turn nutrition data into meaningful insights.

## Objectives

* Track daily calorie, protein, fibre, fat and carbohydrate intake.
* Calculate personalized nutrition targets.
* Compare actual consumption with daily targets.
* Analyze nutrition data using SQL and Python.
* Build an interactive Power BI dashboard for nutrition monitoring.

## Technologies Used

* **Microsoft Excel** – Data preparation and nutrition calculations
* **SQL / MySQL** – Data querying and analysis
* **Python** – Data processing and analysis using Pandas
* **Power BI** – Interactive dashboard and visualization
* **CSV** – Data storage and exchange
* **GitHub** – Version control and project collaboration
